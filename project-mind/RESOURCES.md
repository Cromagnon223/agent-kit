# Resources Kyle wants on hand

Look here before building anything, and prefer these over starting from scratch. Check each item's license before using it (per-asset on itch.io, Freesound and Kenney; attribution needed for CC BY). One-liners come from each site's or README's own text, fetched 2026-10-13.

## Game engine and assets

- https://godotengine.org — Free and open source 2D and 3D game engine. (License: see the site's License page; not checked.)
- https://lospec.com — Free online tools, palettes, gallery and resources for pixel art and other low-spec digital art.
- https://freesound.org — Collaborative database of sounds, licensed under Creative Commons (which CC license varies per sound; not checked).
- https://game-icons.net — Free collection of 4,000+ SVG and PNG game icons, licensed CC BY 3.0 (credit required).
- https://kenney.nl/assets — Kenney's library of 2D, 3D, UI, audio and texture assets for game developers. (License not stated on the page; not checked.)
- https://opengameart.org — Community site for free game art, music and sound effects under free licenses (CC0, OGA-BY, CC-BY, CC-BY-SA, WTFPL, public domain; varies per asset).
- https://itch.io — Site to find and share indie games, with a "Game assets" category. (Licensing per item; not checked.)

## Agent and skill libraries on GitHub

- https://github.com/morluto/rea — "One MCP for reverse engineering across binaries, applications, and runtime behavior"; lets AI agents analyze software locally. MIT (third-party material keeps its own license).
- https://github.com/kuratlielia/arc-library — Free, open source collection of React components and blocks with smooth, physical motion, added via the shadcn CLI or by copying files. MIT.
- https://github.com/addyosmani/agent-skills — Production-grade engineering skills as Markdown workflows that help AI coding agents follow senior-engineer practices across development phases. MIT.
- https://github.com/anthropics/claude-quickstarts — Collection of projects for quickly building applications on the Claude API. MIT.
- https://github.com/anthropics/knowledge-work-plugins — Open-source plugins that turn Claude into a specialist for specific job roles; built for Claude Cowork, also works with Claude Code. Apache-2.0.
- https://github.com/wshobson/agents — Collection of plugins, agents, skills and commands for multiple AI coding tools. MIT.
